# 1000PRO AUTO TRADER

1000PRO AUTO TRADER 설치 파일 배포 및 자동 업데이트용 저장소입니다.

## 다운로드

[Releases](https://github.com/cosolove/auto-trader/releases/latest)에서 최신 버전의 `1000PRO_Setup_vX.Y.Z.exe`를 다운로드하여 실행하세요.

v4.3.2 이하 사용자는 v4.3.3을 한 번 직접 설치해야 이후 자동 업데이트를 이용할 수 있습니다.

Google 서비스 계정 인증키는 설치 파일에 포함되어 있지 않습니다. 새 PC에서는 프로그램 설정 화면에서 본인의 인증키를 등록해 주세요.
